三方 Docker 部署 · 路径映射与界面填法

核心：三个容器共享同一个真实目录，只是各自看到的路径名不同 —— 界面上两个路径字段填的是不同容器的视角。
① 一个真实目录，三方各挂一次
宿主机 / NAS
/mnt/music-data/　← 唯一真相源（宿主机上的实际文件夹，名字随你）
　├── 歌单同步/　　　　├── 我喜欢的/　　　　└── 手动下载/ …
▼ 同一个目录，挂载三次 ▼
lxserver下载源
/server/music

  • 歌曲下载落盘
  • 写入标签/封面/歌词
  • 需读写
音乐服务器Emby 等

  • 建播放列表
  • 只读即可

  • 校验/重命名/移动文件

③ 三个最容易踩的坑
✅ 同一个真实目录，三个容器各挂一次（没挂的容器就是看不到文件）。
✕ 把「LX 下载目录」填成 Emby 视角的 /media/music —— 本项目在它自己的容器里找不到这个路径，会读写失败。
✕ 「媒体库根路径」填成挂载点 /media/music —— 应填你在 Emby 后台给音乐库选的那个文件夹（可点「探测媒体库」自动识别）。
💡 本机直接 npm run dev（无容器）时没有视角差异：两个路径都填宿主机实际路径即可。
